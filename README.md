## Editing

Open `index.html` in a browser; no build or installation is required. CSS, JavaScript, SVG artwork, and synthesized music are embedded in the file. Google Fonts is the only optional external styling dependency.

Edit the `INVITATION` object near the bottom of `index.html` to change names, date, time, venue, Maps link, inviting families, contact numbers, or an optional photograph. The ceremony timezone is fixed to India Standard Time. No unconfirmed end time is added to the calendar event.

The live countdown, calendar download, native/WhatsApp sharing, music controls, and reduced-motion support are included. The live website is hosted through Sites; GitHub source changes do not automatically redeploy that hosting. This file is also ready for any static web host.
